# gloss

translate a phrase. tap a word. that's it.

no account. no cloud. no nonsense — everything runs on your phone, offline, after a one-time ~30 MB model download per language pair.

---

**type** → get the translation as you go  
**tap any word** → see just that word's meaning  
**swap** → flip languages instantly  

59 languages. built on ML Kit.

---

```bash
./gradlew assembleDebug
```
